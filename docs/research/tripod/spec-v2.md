### 1.2 1단계: 시장 국면 판정 (히스테리시스)

| 조건 | 국면 | 출처 |
|---|---|---|
| 지수 > 250일선 × 1.01 | **상승** | 🎙22:05 "1% 위", 🖥21:58 "1% 넘게 위" |
| 지수 < 250일선 × 0.95 | **하락** | 🎙22:12 "5% 넘게 아래" ✔ |
| 그 사이(-5% ~ +1%) | **직전 상태 유지** | 🎙22:17 "직전의 내 포트폴리오 상태를 유지", 🖥 "어제 상태 유지" |

설계 의도는 "나갈 때는 신중하게, 들어올 때는 빠르게"(🎙22:47 ✔)이고, 경계선 근처에서 사고팔기를 반복하는 것을 막기 위한 완충 구간입니다.

### 1.3 2단계: 보유 자산 결정

| 국면 | 추가 조건 | 보유 | 실효 레버리지 | 출처 |
|---|---|---|---|---|
| 상승 | VIX10 **< 28** 그리고 52주 낙폭 **9% 이내** | TQQQ 100% | 3.0배 | 🎙22:52 ✔ |
| 상승 | VIX10 **≥ 28**("넘었거나") 또는 낙폭 **9% 초과** | QQQ 50% + QLD 50% | 1.5배 | 🎙23:15 ✔ |
| 하락 | VIX10 **< 18** | QQQ 50% + QLD 50% | 1.5배 | 🎙23:38 ✔ |
| 하락 | VIX10 **≥ 18**("이상") | 현금 100% | 0배 | 🎙23:38 ✔ |

**3단계:** 결과가 어제와 같으면 아무것도 하지 않습니다(🎙23:53, 🖥 슬라이드 문구 ✔).

### 1.4 의사코드 (명시된 부분만)

```
매 거래일 t, 장 마감 후:
  MA250[t] = mean(NDX_close[t-249..t])
  VIX10[t] = mean(VIX_close[t-9..t])
  DD52[t]  = NDX_close[t] / max(NDX[t-L+1..t]) - 1    # L = 52주. 계산 방식은 미명시(§3 참고)

  if   NDX_close[t] > 1.01 * MA250[t]: regime = UP
  elif NDX_close[t] < 0.95 * MA250[t]: regime = DOWN
  else:                                regime = regime[t-1]   # 해석 A. §3의 V3 참고

  if regime == UP:
      target = TQQQ_100 if (VIX10 < 28 and DD52 >= -0.09) else QQQ50_QLD50
  else:
      target = QQQ50_QLD50 if VIX10 < 18 else CASH

  if target != target[t-1]: 체결(시점은 §3의 V1)
```

## 7. 재현 판정 기준 제안

- **핵심 4개 지표**(트라이팟 CAGR, MDD, 10년 중간값, 10년 최악): 비용 기본값(V8 기본)에서 CAGR ±3%p, MDD ±5%p 안에 들어오면 "재현됨"으로 봅니다.
- **V1~V3 조합 12가지** 가운데 어떤 조합에서도 32.9% ±3%p가 나오지 않으면 "재현 불가 또는 비공개 조건 존재"로 판정합니다.
- 비교 대상(QQQ·QLD·TQQQ 보유)의 수치가 맞으면 데이터와 가상 상품 구성은 맞는 것이므로, 트라이팟 쪽 차이는 규칙 해석(V1~V6, V10, V16) 문제로 좁혀집니다.
- **표본 외 점검**(영상 범위 밖이지만 과적합 여부 판단용): 파라미터를 고정하고 1985~1990 구간, 또는 S&P500·SPXL 같은 다른 지수에 적용해 성과가 얼마나 떨어지는지 확인합니다.
