# 트라이팟 대안 전략: 사전 등록 평가

- 작성 2026-10-24. 명세(결과를 보기 전에 커밋): [tripod/candidates-spec.md](tripod/candidates-spec.md), 커밋 `5ac9a0e`
- 코드: `scripts/tripod/strategies.mjs`(규칙), `scripts/tripod/alternatives.mjs`(평가). 출력 원문: `tripod/alternatives-output.txt`
- 앞선 검증: [tripod-verification.md](tripod-verification.md) §9(비판적 점검)·§10(QQQ 대비 우위 지속성)

## 1. 결론

1. **사전 등록한 후보 4개 중 기준을 통과한 것은 "트라이팟 2배판"(TQQQ 자리에 QLD) 하나다.** 다른 시장과 10년 가상 경로에서 트라이팟보다 나았고 환경 악화 기준은 못 넘었다(3개 중 2개 충족). QQQ 보유보다 낫다는 기준도 통과했다.
2. 2배판은 나스닥100에서 세후 CAGR이 트라이팟보다 5.1%p 낮다(21.9% 대 27.0%). 대신 MDD가 12.5%p 얕고(-53.6% 대 -66.1%), 10년 가상 경로의 원금 손실 확률이 낮다(10.4% 대 18.3%, 블록 63일). 변동성이 1.25배로 커지면 트라이팟은 QQQ에 지지만(-3.0%p) 2배판은 비긴다(+0.3%p). **수익을 덜 가져가는 대신 덜 깨지는 판**이다.
3. 이론에서 출발한 추세 앙상블 계열 셋(TE3, TEV3, TEV2)은 모두 탈락했다. 하락장의 반등마다 짧은 이동평균을 넘으며 레버리지를 다시 실었다가 잃었다(2000~2003년 노출 변경 142회, 트라이팟 9회). 트라이팟의 "250일선 × 1.01을 넘어야 상승 국면 복귀" 같은 완충 장치가 실제로 중요하다는 반증이다.
4. 다른 시장에서는 어떤 후보도 1배 보유를 확실히 이기지 못했다(최대 8개 중 4개). **나스닥100 밖에서도 통하는 레버리지 규칙은 이번 후보 중에는 없다.**

## 2. 후보와 판정 기준

명세 그대로다. 모든 전략은 다음 거래일 종가 체결, 편도 5bp, 한국 세후 모델이다.

| 기호 | 규칙 |
|---|---|
| 트라이팟 | 영상 규칙, 최대 3배 |
| T2 트라이팟 2배판 | 트라이팟 규칙, TQQQ 100% 자리에 QLD 100% |
| TE3 추세 앙상블 3배 | 100·150·200·250·300일선 중 종가가 위에 있는 비율 s, 노출 3s |
| TEV3 추세 앙상블 + 상대 변동성 3배 | min(3s, 3 × 5년 중앙 변동성 ÷ 20일 변동성), 0.5배 단위로 내림, 변동성 상한은 월말 갱신 |
| TEV2 같은 규칙 2배 | 최대 2배 |

트라이팟보다 낫다 = ① 다른 시장, ② 10년 가상 경로, ③ 환경 악화 중 둘 이상 충족. QQQ보다 낫다 = 나스닥100 세후 CAGR이 QQQ보다 높고, 블록 63일 가상 경로에서 QQQ보다 많이 남길 확률 50% 초과.

추세 앙상블은 하락장 반등에서 100·150일선을 넘을 때마다 노출을 다시 올렸다. 트라이팟은 하락 국면에서 250일선 × 1.01을 넘어야 복귀하므로 반등에 덜 속았다. 이 관찰에서 나온 개선안(앙상블에 완충 구간 추가 등)은 이번 결과를 보고 만든 것이므로, 시험한다면 새로 사전 등록하고 실전 기록으로 판단해야 한다.
