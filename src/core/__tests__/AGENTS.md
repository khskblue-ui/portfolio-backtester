## AI 에이전트 지침

### 이 디렉토리에서 작업할 때

- **골든 값은 손계산으로 검증된 앵커다** (32주/$3,200/$154, $1,650, 11,739% 등).
  구현 변경으로 값이 달라지면 "테스트를 통과하게" 숫자를 맞추지 말고, 손계산을 다시
  도출해서 근거와 함께 갱신할 것. 도출 과정은 테스트 제목·주석에 남긴다.
- 새 엔진 기능 = 골든 1개 + 프로퍼티 1개 이상. 난수가 필요하면 `lcg` 시드 고정.
- 네트워크 접근 금지 원칙 유지 — fetch가 필요한 테스트는 스텁으로.
- `-HIST` 테스트 후 `resetHistAssetsCache()`로 모듈 캐시 정리 (`afterEach` 패턴).
